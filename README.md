# Thrive Weekly Wellness Guide

generate the website with attractive and in green color and with beautiful pictures also with frontend backend database connection code

Build a complete, fully functional, attractive, green-themed full-stack website titled “Digital Health Support and Preventive Care Website for Adults Aged 20–35 Years” called HealthMate – Your Personal Wellness Guide. Use React, TypeScript, Tailwind CSS, Lucide icons, Supabase authentication, and a PostgreSQL database. Design the website with a beautiful green and white theme, mint backgrounds, emerald green buttons, attractive health-related illustrations, rounded cards, smooth animations, and a friendly, responsive layout for desktop and mobile. First, users must register with their full name, email, password, and age between 20 and 35, then log in securely. Include forgot password, password reset, protected pages, and logout functionality. After login, display three attractive category cards: Students, Married People, and Job Holders. When users select a category, collect their health and lifestyle details through a well-designed form, including age, sleep hours, daily water intake, physical activity, exercise frequency, screen time, sitting time, eating habits, stress level, smoking, alcohol consumption, and optional health concerns, symptoms, and personal wellness goals. Provide Save Profile, Edit Details, and Continue buttons, and store all submitted information securely in the database. After saving, display a personalized dashboard based on the user's selected category and answers, with multiple useful suggestions, educational reading materials and book recommendations, beginner-friendly exercise plans, healthy eating guidance, sleep improvement tips, hydration reminders, stress management techniques, preventive healthcare awareness, daily wellness checklists, weekly plans, and progress tracking. Students should receive study-life balance, exam-stress management, and student wellness suggestions; married people should receive healthy daily routines, shared meal planning, work-life balance, and personal wellness suggestions; job holders should receive desk ergonomics, movement breaks, workplace stress management, and healthy work routines. Build a working recommendation engine that changes suggestions according to the user's saved lifestyle details instead of displaying the same generic information to everyone. Include separate pages for the dashboard, profile, health assessment, reading corner, exercise plans, preventive care, weekly progress, privacy policy, and about the project. Allow users to bookmark resources, complete wellness goals, update their information, and view their saved progress after logging in again. Use genuine, verified educational resources and working links. Implement a real backend and persistent database using Supabase, with proper database tables, relationships, validation, authentication, and Row Level Security policies so users can access only their own private information. Include secure environment-variable configuration, an .env.example file, SQL schema and setup instructions, reusable components, clean project folders, error handling, loading states, and a detailed README. Never expose private keys or secrets in frontend code. Add a privacy policy, make sensitive health fields optional, and clearly state that the website provides general health education and preventive-care awareness, not medical diagnosis or treatment. Test the complete flow from registration to login, category selection, health details submission, database storage, personalized recommendations, profile editing, progress tracking, and logout. Fix broken buttons, links, and database errors before completion. Ensure all pages are connected, all features work correctly, and the complete source code is organized and ready to push to GitHub. Do not create only a static frontend or fake authentication; build a functional full-stack application with a real database and personalized user experience.
